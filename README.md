# 📊 Data Analyst Job Market & Skills Insights

An end-to-end exploratory data analysis on 60,000+ real-world Data Analyst job postings to identify top industry skill requirements, salary benchmarks, and remote work availability.

---

## 🎯 Key Findings & Executive Summary

1. **Core Technical Stack in Demand:**
   - **SQL** and **Excel** are the most frequently requested baseline tools, followed by **Python, Tableau, and Power BI**.
2. **Workplace Flexibility:**
   - **45.2%** of all posted analyst roles offer remote work flexibility, showing substantial opportunities for remote-first positions.
3. **High-Paying Skill Drivers:**
   - Advanced data engineering and cloud workflow tools (**PyTorch, PySpark, Docker, Airflow, PL/SQL**) lead with median salaries exceeding **$120,000/year**, proving that programmatic and database proficiency commands higher pay.
